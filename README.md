# AI 辦公室

AI 辦公室是一款在瀏覽器運行的小型接案公司模擬器。公司會自動安排員工工作、接案、招募及擴張。你可以控制模擬速度，觀察工作進度、公司財務與員工狀態如何隨時間變化。

## 本機啟動

使用 Node.js 24 或更新版本（含 npm）。若從 GitHub 複製專案，請先以有權存取此私人儲存庫的帳號完成 Git 驗證。

```sh
git clone https://github.com/GBO0101/TOWN.git
cd TOWN
npm ci
npm start
```

開啟 [http://localhost:3000](http://localhost:3000)，辦公室載入後會自動開始模擬。在終端機按 `Ctrl+C` 可停止伺服器。

## 操作方式

- 使用右上角的「暫停」與「繼續」控制時間。點擊速度按鈕可切換 1×、2×、3×、5×、10×。
- 點擊場景中的人物或底部角色卡，可查看職等、健康、目前任務與記憶。
- 展開右側的公司成長、專案進度、自研與被動收入及辦公室日誌，查看招募、投入人數、剩餘工時與營運事件。
- 點擊「重置」或重新整理頁面，模擬會從第 1 天重新開始。

## 模擬內容

- 員工依職能回自己的座位工作，也會休息、開會或外勤。午餐工作效率為平時的 75%，健康會影響產出，累積工作經驗後可晉升並調薪。
- 公司依產能與成本承接案件，交付後依帳期收取尾款。每天 20:30 統一扣除當天到期的薪資、租金及其他費用，頁首顯示現金、淨資產與當日損益。
- 老闆依資金和人力需求決定招募、補人及擴張。新員工報到後會取得座位並加入派工。
- 公司在中後期可投資自研網站或遊戲，由業務開發付費客戶。客戶越多，收入及伺服器等用量費用越高。上線產品會不定期產生維護案，維護完成沒有額外報酬，逾期會流失客戶。

## 開發與測試

前端使用 HTML、CSS 與 JavaScript。`index.html` 是頁面入口，`js/` 負責模擬與畫面更新，`styles/` 和 `assets/` 放置樣式及圖像，`server.js` 提供本機伺服器。

在專案目錄執行以下指令。第一個執行 Vitest 測試，第二個檢查前端腳本所需的靜態 HTML ID。

```sh
npm test
node check_ids.js
```
